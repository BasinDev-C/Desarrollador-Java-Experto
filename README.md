# Desarrollador Java Experto 🚀

Repositorio oficial de desarrollo, arquitectura, patrones de diseño, buenas prácticas y proyectos avanzados en Java (Spring Boot, Microservicios, Concurrencia, Clean Code, Testing).

## 📌 Estructura del Repositorio

- `/src` - Código fuente de proyectos y ejemplos de arquitectura.
- `/patterns` - Implementación de patrones de diseño (Creacionales, Estructurales, Comportamiento).
- `/docs` - Documentación técnica y guías de arquitectura Java avanzada.

## 🛠️ Tecnologías y Stack
- **Java 17 / 21 LTS**
- **Spring Boot / Spring Cloud**
- **JPA / Hibernate / PostgreSQL**
- **JUnit 5 / Mockito / Testcontainers**
- **Docker / Kubernetes**
